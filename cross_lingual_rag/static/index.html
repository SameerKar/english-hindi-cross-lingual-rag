🤖 AI Model & API Key Transparency Guide

1. Why does `gpt-4o-mini` appear in `config.yaml`?
`gpt-4o-mini` is the default model configuration label in the project's hyperparameter config file.

2. Did it use an API key or charge anything?
No! Absolutely not. In src/generation.py, the code inspects OPENAI_API_KEY. Since no key was set in your environment, it automatically switched to Deterministic Context-Grounded Synthesis ($0 cost). It parses the top retrieved chunk passage and cites the facts directly without calling external APIs.

3. Can I connect a Real Free LLM?
Yes! You can use Google Gemini 2.0 Flash (100% Free at Google AI Studio) or Ollama (100% Free offline local LLM). Just set: 

$env:GEMINI_API_KEY = "YOUR_FREE_KEY"
and the generator will connect to Gemini live at $0 cost!
