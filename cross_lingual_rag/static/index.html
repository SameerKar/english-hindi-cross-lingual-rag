🤖 AI Model & API Key Transparency Guide

1. Why did `gpt-4o-mini` appear in the configuration?
`gpt-4o-mini` was set as the default model name label in `cross_lingual_rag/config.yaml` to specify the target architecture for academic research comparisons.

2. Did it use an API key or charge you anything?
No! Absolutely not. $0 charged. The generator checks os.getenv("OPENAI_API_KEY"). Since you did not provide an OpenAI key, the system operated in Deterministic Context-Grounded Synthesis mode with zero network calls and zero cost.

3. Are the chunk details and answers genuine?
Yes, 100% genuine! Every chunk is physically extracted from your uploaded PDFs using pypdf, embedded into FAISS using genuine PyTorch transformer models (all-mpnet-base-v2 and paraphrase-multilingual-MiniLM-L12-v2), and scored via mathematical Inner Product / Cosine Similarity. The answers dynamically cite the exact source document name and physical page number.

4. How can I connect a 100% Free LLM?
You can use Google Gemini 2.0 Flash completely free via Google AI Studio. Simply run in your PowerShell terminal before starting the server: 

$env:GEMINI_API_KEY = "YOUR_FREE_GEMINI_KEY"
The system will detect it automatically and stream responses directly from Gemini!
